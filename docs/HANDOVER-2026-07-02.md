## 3. 作業環境の注意（Cowork サンドボックス固有・重要）

このセッションで踏んだ罠。同じ環境で作業するなら必読:

- **uv sync は不可**: mediapipe が linux/aarch64 wheel 無し。代わりに専用 venv を作成済み: `/sessions/<session>/dasvenv`（セッションが変わると消える。再作成手順: `python3 -m venv ~/dasvenv && ~/dasvenv/bin/pip install pytest pytest-asyncio pytest-xdist pydantic pydantic-settings python-dotenv tenacity typer structlog rich anyio openai networkx tiktoken websockets respx click numpy pyvis ruff mypy`）
- **テスト実行コマンド**（/tmp に nobody 所有の残骸があり os.replace が失敗するため、mount namespace で /tmp を差し替える）:
  ```
  cd <repo> && unshare -Urm sh -c 'mount -t tmpfs tmpfs /tmp && env PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 ~/dasvenv/bin/python -m pytest tests/unit -q -p no:cacheprovider -n 8'
  ```
- **bash 呼び出しは45秒制限・バックグラウンドプロセスは呼び出し終了で死ぬ** → pytest-xdist の `-n 8` で45秒以内に収める
- **git 操作でロック残骸が出たら**: `.git/index.lock` の削除にはファイル削除許可が必要（`allow_cowork_file_delete` を使う。既に一度許可済み）。git stash はこの環境で不安定なので**使わない**（コミットは問題ない）
- mypy は `--python-version 3.12` を付ける（venv の numpy stub の都合）。strict エラー360件は既存負債
