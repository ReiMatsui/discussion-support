# 11. 評価

## 1. 技術評価（人手注釈あり）

| 指標 | 内容 |
|---|---|
| 焦点の一致率 | 一定間隔で抜き出した時刻での、システムと注釈者の焦点の一致 |
| 焦点切替の検出 | 時間の許容幅つきの適合率・再現率と WindowDiff。EchoMind（28% / 58%）との比較用に厳密一致の値も併記 |
| 焦点切替の遅れ・ちらつき | 注釈上の切替から表示までの時間。切り替えた後すぐ戻った回数 |
| 注釈者間一致 | 焦点・立場・決定を2人で注釈し、人間同士の一致を上限の目安にする |
| ノードの網羅率 | 注釈した主要な問い・案のうち、構造に現れた割合 |
| 立場の印の適合率（最重視） | 表示した印のうち本人の立場として正しい割合。話者の誤りと立場の誤りを分けて数える |
| 立場の印の再現率 | 注釈した立場のうち、印として表示された割合 |
| 決定の適合率・再現率 | 自動で付けた決定と、まとめの段階で確定した決定のそれぞれについて |
| 脱線の検知 | 検知の遅れ、1 時間あたりの誤警告、役立つ寄り道を脱線と判定した件数 |
| 判定モデルの比較 | 候補ごとの精度、遅延、確率の較正（[03_utterance_judgement.md](03_utterance_judgement.md)） |

## 2. ログから計算する指標

- 1 分あたりの画面の変更数（`display_commit` の件数と種類）
- ラベル長の分布と上限超過率
- 表示要素ごとの遅延（p50 / p90）と区間ごとの内訳（発話終端 → 音声認識の確定 → 速い層 →
  遅い層 → 画面への反映）。QUD 試作の遅延計測を流用できる
- 記録されたが適用されなかった構造提案の件数
- AI の発話の回数・種類・長さ、まとめの段階の所要時間と確認の件数

## 3. 人を対象とした評価【検討中】

- **オンライン視聴実験**（修論方針 `docs/research/thesis_path_online_2026-09.md` に合わせる）:
  録画した議論を条件別に視聴し、「いま何を議論しているか」「何が決まったか」「誰がどの案か」への
  正答率と回答時間を測る。途中から視聴して追いつく課題を含める。理解の助けになるかを測る。
- **少人数のライブ試行**: 視聴実験では測れない、注意の奪われ方と、名前つきの懸念が発言を
  ためらわせるかを観察する。条件は「AI の声のみ」と「静かな画面＋区切りの声」の2つを案とする。
