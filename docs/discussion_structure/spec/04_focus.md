# 04. 焦点の追跡

関連する設計判断: [ADR-007](../decisions/ADR-007-focus.md)

焦点は「いま議論されている問い」である。常に1つ（議題の根を含む）とし、案は焦点にしない。

## 1. 焦点の移動の種類【合意】

| 移動 | 例 | 木の上の操作 |
|---|---|---|
| 継続 | 同じ問いを話し続ける | なし |
| 深掘り | 「その費用は誰が持つの？」 | 子の Issue へ |
| 戻る | 「話を戻すと…」 | 祖先の Issue へ |
| 横移動 | 「それとは別に、告知方法は？」 | 別の枝の Issue へ |
| 進行・脱線 | 雑談、段取り | 焦点は変えない（[08_drift.md](08_drift.md)） |

## 2. 判定の方法【合意。数値は暫定値】

1. 速い層が、発話ごとに「どの問いについての発話か」を確率つきで判定する
   （[03_utterance_judgement.md](03_utterance_judgement.md)）。
2. 焦点を隠れた状態とみなし、発話ごとの確率を観測として信念を更新する（対話状態追跡の考え方）。
   - 「継続」の事前確率を高くし、木の上で近い移動（親・子）ほど起きやすくする。
   - 話題転換の合図がある発話では、移動の事前確率を上げる。
   - 相槌は観測に使わない。長い実質発話ほど重みを大きくする。
3. 別の Issue の事後確率が **0.7** を超え、それが **2 発話かつ 10 秒**続いたときだけ、表示中の
   焦点を切り替える。
4. 「新しい問い」と判定された発話は、ノードの作成規則（[05_nodes.md](05_nodes.md)）に従って
   問いを作り、作成後は焦点の候補に入る。
5. 焦点が移っても、元の Issue の解決状態は変えない（[07_resolution.md](07_resolution.md)）。
