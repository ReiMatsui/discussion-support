# 05. ノードの作成と配置

関連する設計判断: [ADR-008](../decisions/ADR-008-node-creation.md)、
[ADR-004](../decisions/ADR-004-answer-types.md)

基本方針: **既存ノードに「付ける」のが基本で、「作る」のは例外**。

## 1. 発話ごとの処理【合意】

| 速い層の判定 | 処理 |
|---|---|
| 既存の Issue / Position に関する発話 | そのノードに根拠発話・立場を追加する（構造は変えない） |
| 新しい問いを含む | §2 の作成規則へ |
| 新しい案を含む | §2 の作成規則へ |
| 構造に関係しない（相槌・進行・脱線） | 何もしない |

既存ノードか新規かで判定が拮抗した場合は、**既存ノードに付ける側に倒す**。

## 2. 作成のきっかけ【合意。数値は暫定値】

| きっかけ | 例 | 作る時点 | 作るもの |
|---|---|---|---|
| 全員に向けた明示的な問い | 「費用はどうする？」 | すぐ | Issue |
| 焦点の問い（選択型・自由回答型）への案 | 「寄付を募ったら？」 | すぐ | その Issue の下に Position |
| 焦点の是非型の問いへの代わりの案（どちらか一方） | 「紙じゃなくてバイオプラでは？」 | すぐ | 選択型へ格上げ（§5） |
| 焦点の是非型の問いと両立する追加の案 | 「紙に加えて、マイストロー持参も勧めよう」 | 他の参加者が応答した時点 | 別の是非型 Issue（格上げしない） |
| 焦点と関係しない単独の提案（暗黙の問い） | 「いっそ廃止しよう」 | 他の参加者が応答した時点 | 是非型 Issue |
| 問題の提示（暗黙の問い） | 「予算が足りない」 | 他の参加者が応答した時点 | 自由回答型 Issue |
| 懸念の中身が話題になった | 「紙っていくら高いの？」 | 他の参加者がその懸念を話題にした時点 | 子の Issue（「紙ストローの費用は問題ないか？」） |

- **暗黙の問い**とは、問いの形で言われていないのに、実質的に新しい問いを持ち込む発話である。
  「単独の」は、いまの焦点の問いに答える提案ではないことを指す（焦点の問いへの答えなら案になる）。
- 「応答」は、別の話者による実質的な発話で、その候補に関するもの（賛成・懸念・質問・補足）。
  相槌は数えない。**60 秒**応答がなければ候補を捨てる。
- 懸念を別の案の理由に使っただけ（「バイオプラの方が安い」）では、子の Issue は作らない。
- 脱線中（[08_drift.md](08_drift.md)）の発話からはノードを作らない。

例:

```text
A: ストロー、紙に切り替えない？          → 焦点と関係しない単独の提案。応答待ち
B: いいと思う、でも高くない？            → 応答あり → 是非型「紙ストローに切り替えるか？」
                                            A 賛成（提案者）、B 懸念（中身「費用」は内部に保存）
C: 紙よりバイオプラの方が安いよ          → 代わりの案 → 選択型「ストローを何にするか？」へ格上げ
                                            案「紙ストロー」（A 賛成・B 懸念を移す）「バイオプラ」（C 賛成）
```

## 3. Issue にしない問い【合意】

| 種類 | 例 | 扱い |
|---|---|---|
| 確認・聞き返し | 「それって〜ってこと？」 | ノードにしない |
| すぐ答えが出る事実確認 | 「締切いつだっけ？」 | 議論が続いた場合だけ Issue にする |
| 合意の確認 | 「じゃあ A でいい？」 | 既存 Issue の決定の手がかり（[07_resolution.md](07_resolution.md)） |
| 進行の問い | 「次は何を話す？」 | 焦点の移動の手がかり |
| 反語 | 「そんなの誰が使うの？」 | 懸念の表明として扱う（[06_stances.md](06_stances.md)） |

## 4. 同一性（重複を作らない）【合意】

- Issue: **同じ答えで解決される問いは同じ Issue** とする。言い換えは既存 Issue への言及とする。
- Position: **同じ行動・選択を指す案は同じ Position** とする。条件や程度の違い（「紙ストロー」と
  「希望者だけ紙ストロー」）は同じ Position にまとめ、違いは根拠発話に残す。
- 作る前に、速い層の選択肢に既存ノードを並べて同一性を判定し、遅い層にも兄弟ノードのラベルを
  渡して近い重複を避ける。

## 5. 是非型から選択型への格上げ【合意】

**きっかけ**: 焦点の是非型の問いに、**代わりの案**（どちらか一方を選ぶ案。「A じゃなくて B」
「A より B」）が出たとき。両立する**追加の案**（「A に加えて B も」）では格上げせず、別の是非型の
問いとして扱う（§2）。速い層は「代わりの案か、追加の案か」を判定する
（[03_utterance_judgement.md](03_utterance_judgement.md)）。

**手順**

1. 問いが**決定済み**なら、すぐには格上げしない。先に決定の再開の規則
   （[07_resolution.md](07_resolution.md) §4: 他の参加者の応答があれば未解決に戻す）を適用し、
   未解決に戻った時点で格上げする。
2. 問いのノードは**同じ ID のまま**、答えの型を選択型に変え、ラベルを作り直す
   （「紙ストローに切り替えるか？」→「ストローを何にするか？」）。表示済みのラベルが自動で変わる
   唯一の変更である。
3. 案ノードを2つ作る。元の提案（「紙ストロー」）と、新しい案（「バイオプラ」）。
4. 問いに付いていた立場を、**元の提案の案へそのまま移す**（賛成は賛成、懸念は懸念。懸念の中身、
   話者、確信度、根拠発話も一緒に移す）。移したことを遷移イベントとして記録する。
5. 新しい案の提案者に、その案への賛成を付ける。
6. 子の問いは**動かさない**（問いのノードが同じなので、子は付いたままになる）。元の提案だけに
   関する子（「紙ストローの費用は問題ないか？」）は、元の提案の案の下への付け替えを**構造提案**として
   記録し、まとめの段階で確認する。どの案にも関係する子（「いつから切り替えるか？」）はそのまま。
7. 画面には1回の反映でまとめて出し、印はゆっくり移す（[09_display.md](09_display.md)）。

**補足**

- 「今のままでいい（切り替えない）」という立場は、元の提案の案への懸念として表す。「現状維持」の
  案ノードは自動では作らない。誰かが「今のままでいい」と明言した場合は、代わりの案として案ノードに
  する。
- 新しい案の提案者が元の提案を比較で否定していても（「紙より安い」）、元の提案への懸念は自動では
  付けない。速い層の判定で懸念の確率が閾値を超えたときだけ付ける（[06_stances.md](06_stances.md)）。

例:

```text
（格上げ前）是非型「紙ストローに切り替えるか？」   A 賛成（提案者）／B 懸念（中身: 費用）
            └ 子「いつから切り替えるか？」
C: 紙よりバイオプラの方が安いよ                    ← 代わりの案
（格上げ後）選択型「ストローを何にするか？」
            ├ 紙ストロー   A 賛成／B 懸念（中身: 費用）    ← 立場を移す
            ├ バイオプラ   C 賛成（提案者）
            └ 子「いつから切り替えるか？」                 ← 動かさない
```

## 6. 配置（親の決定）【合意】

| 親の候補 | 起きやすさ |
|---|---|
| 焦点の Issue | 最も高い |
| 焦点の下の Position（「その案だと費用は？」） | 高い |
| 焦点の祖先、根（議題） | 中 |
| 別の枝の Issue | 低い |

- 速い層が候補から確率つきで選び、焦点に近いほど事前確率を高くする。
- Position の親は選択型・自由回答型の Issue に限る。
- 木の深さはデータ上は制限しない。

## 7. ラベルの生成【合意】

- 遅い層の LLM が、根拠発話、親までの経路、兄弟ノードのラベルからラベルと答えの型を作る。
- 規則で検査する: 長さ（問い ≤ 20 字、案 ≤ 16 字）、問いは疑問形、個人名を含まない。違反したら
  1 回だけ作り直し、なお違反なら作成を見送って構造提案として記録する。
- できるだけ参加者の言葉を使う。音声認識の信頼度が低い固有名詞は使わない。
- ノードはラベルが確定してから表示する（仮の表示はしない）。生成中に届いた関連発話は保留し、
  作成後に付ける。
- 案を出した本人には、その案への賛成を自動で付ける。
- 【検討中】ラベルの文体の規則（「〜するか？」で揃えるか、「費用は誰が持つ？」のような短い形を
  許すか）。
