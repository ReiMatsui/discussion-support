# ADR-004: 問いを答えの型で3分類し、是非型から選択型への格上げを許す

- 状態: 採用
- 日付: 2026-10-01（3分類と格上げ）、2026-10-06（格上げの手順）
- 関連仕様: [02_data_model.md](../spec/02_data_model.md)、[05_nodes.md](../spec/05_nodes.md)

## 背景

問いのノードにどんな種類があるか、案や立場をどう付けるかを決める必要があった。また、すべての問いを
網羅できるかが問われた。

## 選択肢

| 案 | 内容 |
|---|---|
| A. 問いを区別しない | すべての問いの下に案を付ける |
| **B. 答えの型で3分類** | 是非型・選択型・自由回答型 |

## 決定

- B を採用する。是非型は案ノードを作らず問い自体に立場を付け、選択型・自由回答型は案ノードを付ける。
- 是非型の問いに対立する案が出たら選択型に格上げする。表示済みのラベルが変わるが、許容する
  （高田の判断）。

## 理由

- 実会議の議論図注釈 TAS（Rienks et al. 2005、Verbree et al. 2006）は、問いを自由回答型（Open）・
  二択型（A/B）・是非型（Yes/No）に分けている。AMI コーパスでは是非型 460、自由回答型 244、二択型
  72 で、是非型が最も多い。
- 言語学の疑問文の類型（極性疑問・選択疑問・補充疑問）とも一致し、内容に関する問いはこの3型で
  尽くせる。理由・方法・数量を問う問いは自由回答型に入る。
- 答えの型を持つと、「同じ答えで解決される問いは同じ問い」という同一性の基準を定められる
  （QUD の考え方。[ADR-008](ADR-008-node-creation.md)）。
- 単独の提案（「〜したらどう？」）は是非型の問いとして自然に表せる。対立する提案が出た時点は
  参加者にも分かるきっかけなので、格上げによる表示の変化は唐突にならない。

## 影響

- 問いの形をしていても議論のノードにすべきでない発話（聞き返し、すぐ答えが出る事実確認、合意の
  確認、進行の問い、反語）を除く規則が必要になる。
- 格上げの手順を下の「格上げの手順」で定めた（2026-10-06）。

## 格上げの手順（2026-10-06 追加）

### 論点と決定

| 論点 | 選択肢 | 決定 |
|---|---|---|
| 是非型に付いていた立場 | A. 元の提案の案へそのまま移す／B. 捨てて言い直しを待つ／C. 問いの側に残す／D. 賛成だけ移す | **A** |
| 格上げのきっかけ | 対立する案すべて／代わりの案（どちらか一方）だけ | **代わりの案だけ**。追加の案は別の是非型の問い |
| 子の問い | 内容に応じて付け替える／動かさず、付け替えは構造提案にする | **動かさない** |
| 決定済みの問い | すぐ格上げする／先に決定の再開の規則を適用する | **再開の規則を先に適用** |
| 「現状維持」の案 | 自動で作る／明言されたときだけ作る | **明言されたときだけ** |

### 理由

- **立場を元の提案へ移す**: 是非型「紙ストローに切り替えるか？」への立場は、もともと「紙ストロー
  という案」への立場である。賛成は「紙がいい」、懸念は条件付きの賛成でも反対でも「紙に懸念がある」
  ことを表すため、意味を変えずに移せる。B は直前まであった印が消えて表示が後退して見え、C は
  選択型の問いへの賛否が何への賛否か分からず、D は懸念（「紙は高い」）の情報を失う。
- **代わりの案だけで格上げする**: 両立する案（「紙に加えてマイストロー持参も」）で格上げすると、
  存在しない二択を作ってしまう。
- **子の問いを動かさない**: 問いのノードは同じ ID のまま型とラベルが変わるだけなので、子は付いた
  ままにできる。元の提案だけに関する子を自動で付け替えると、表示済みの構造を自動で組み替えない
  原則（R3）に反するため、構造提案としてまとめの段階で確認する。格上げで画面上動くものを最小限に
  できる。
- **決定済みなら再開を先に**: 決定後の代わりの案は決定の蒸し返しであり、他の参加者の応答がない
  まま格上げすると、決まったことを一人の発言で覆すことになる（[ADR-010](ADR-010-resolution.md)）。
- **現状維持を自動で作らない**: 誰も明言していない案をシステムが作り出すことになる。「今のままで
  いい」という立場は、元の提案への懸念として表せる。
