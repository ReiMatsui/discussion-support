# ADR-007: 焦点は発話ごとの確率を平滑化して切り替える

- 状態: 採用（数値は暫定）
- 日付: 2026-10-01
- 関連仕様: [04_focus.md](../spec/04_focus.md)

## 背景

「いま何を議論しているか（焦点）」の自動追跡は、本研究の中心的な差分である。最も近い EchoMind では、
LLM にその時点で焦点の切替を判断させた試行が適合率 28%・再現率 58% で実用に届かなかった。

## 選択肢

| 案 | 内容 |
|---|---|
| A. LLM にその時点の焦点を直接判断させる | EchoMind の試行と同じ |
| B. 話題の区切りを検出する（話題分割） | 会議の話題分割の手法 |
| **C. 発話ごとの確率を観測とし、平滑化して切り替える** | 焦点を隠れた状態とみなし、木の構造に沿った移動のしやすさを事前確率にする |

## 決定

C を採用する。発話ごとに「どの問いについての発話か」を確率で判定し、「継続」を起きやすく、木の上で
近い移動ほど起きやすくする事前確率で信念を更新する。別の問いの事後確率が閾値を超え、一定時間
続いたときだけ表示を切り替える。

## 理由

| 知見 | 出典 | 設計への反映 |
|---|---|---|
| 焦点はスタックとして動く（下位へ潜る・上位へ戻る・別の枝へ移る） | Grosz & Sidner 1986、Roberts の QUD | 移動を木の上の操作として扱い、近い移動ほど起きやすくする |
| 自然な会話の話題移行は、合図なしに少しずつずれる段階的な移行が多い | Sacks、Jefferson 1984 | 1発話ではなく発話の積み重ねで判定する。「ところで」等の合図は補助的な手がかりにする |
| 会議の話題境界は、粗い粒度では人の判断が一致し、細かい粒度ほど一致しない | Galley et al. 2003、Hsueh et al. 2006 | 焦点は問いの単位にとどめ、案は焦点にしない |
| LLM の一回の判断では切替の誤りが多い | EchoMind | 構造を選択肢として与え、時間方向に平滑化する |
| 発話ごとの観測から状態の信念を更新する方法は対話システムで確立している | 対話状態追跡（Williams et al. 2016） | 同じ枠組みを焦点に使う |

- B の話題分割は、話題の境界を事後に求める手法が中心で、「どの問いに戻ったか」のような木の上の
  位置を扱えない。
- C は、ちらつき（短時間で切り替わって戻る）を、閾値と継続時間で直接抑えられる。

## 影響

- 平滑化の閾値（0.7）、継続時間（2 発話かつ 10 秒）、遷移の事前確率は実データで決める。
- 評価では厳密な境界一致ではなく、時間の許容幅つきの指標を使う（Coen 2025、Pevzner & Hearst 2002）。
  EchoMind との比較用に厳密一致の値も併記する。
- 並行して複数の話題が進む場合の扱いは未決。
