# 設計判断の記録（ADR）

各設計判断について「なぜそうしたか」を残す。形式は ADR（Architecture Decision Record）に
ならい、各文書に次を書く。

- **背景**: 何を決める必要があったか
- **選択肢**: 検討した案
- **決定**: 採用した案
- **理由**: 採用した理由（先行研究・実測・議論での判断）
- **影響**: この決定で生じる制約、残る課題

仕様そのもの（何をするか）は `../spec/` にあり、ここには書かない。文献の詳細は
`../research/references.md`。判断を変えるときは、既存の ADR を書き換えずに状態を「置き換え」に
して新しい ADR を追加する。
