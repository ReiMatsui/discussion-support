# 具体例：同じ資料が「賛否リスト」と「論証グラフ」でどう違って蓄積されるか

題材は先輩(植田 2026)の修論と同じ **「F-REI（福島国際研究教育機構）と浪江町の未来」**。
資料も同種（浪江町HPのPDF・F-REI公開資料・Web検索結果）を用いる。
ここでは「復興資源を F-REI など先端研究・産業の集積に集中させるべきか」を論点に、
**同じ事実集合が、植田システム（賛否2束リスト）と本提案（統合論証グラフ AF）でどう違う形に蓄積されるか**を対比する。

> 注：以下の数値は実在ソースに基づく事実（evidence）。各 evidence の「立場」は事実そのものではなく、
> **対象主張ごとのエッジ**で決まる、という本提案の設計を例示するのが目的。

---

## 1. 入力：議論の発話と、資料から取れる事実

### 議論側（発話 → claim / premise、立場を持つ）

- **C1（Aさん・賛成）**：浪江町は復興資源を F-REI を核とした先端研究・産業の集積に集中させるべきだ
- **C2（Bさん・反対）**：まず帰還住民の生活インフラ（医療・買い物・交通）の再建を優先すべきだ
- **C3（Cさん・懐疑）**：F-REI の雇用が地元の人口回復に本当につながるのかは疑わしい
- **P1（Aさんの根拠 → C1 を支持）**：すでに棚塩産業団地に水素・ロボットの研究拠点が集積している

### 知識側（文書・Web → evidence、中立な事実）

- **E1**：F-REI は2023年に浪江町へ設立。7年間で約1000億円、2029年度までに研究者・職員600人体制を目指す
- **E2**：2025年の住民意向調査で「戻らないと決めている」51.0%、「戻りたい」10.1%、「判断がつかない」24.7%
- **E3**：棚塩産業団地（約49ha）に FH2R（世界最大級の水素製造拠点）と福島ロボットテストフィールドが立地・稼働
- **E4**：町内居住者は約2,400人（震災時人口 約21,500、住民登録 約14,000、帰還率 約17%）

---

## 2. 植田システム流：賛否2束リスト

論点「F-REI に集中すべきか」に対し、賛成根拠の束と反対根拠の束を**均衡的に**並べる：

| 賛成（Pro）の根拠 | 反対（Con）の根拠 |
|---|---|
| E1：7年で約1000億円・600人体制 | E2：51%が「戻らない」 |
| E3：水素・ロボット拠点がすでに集積 | E4：町内居住者は約2,400人と少ない |

特徴：
- 事実は **「賛成の束」か「反対の束」かに固定**される（スタンスが事実に貼り付く）。
- **議論の発話（C1/C2/C3）とは接続されない**。誰のどの主張に効くのかは表現されない。
- 事実どうし・主張どうしの**関係（どれがどれに反論しているか）は持たない**。
- 「均衡的に見せる」までは到達しているが、構造は2列のリスト。

---

## 3. 本提案：統合論証グラフ（AF）

同じ事実を **中立な evidence ノード**として置き、立場は **対象主張ごとのエッジ**で付ける。

```
        E2 ──attack──▶ C1 ◀──support── E1 ──attack──▶ C3
   (戻らない51%)         (F-REI集中)     (1000億/600人)   (雇用は人口回復に繋がらない?)
        │                  ▲                              ▲
     support             attack                          │
        ▼                  │                          (E1がC3にまだ未接続なら
        C2 ──────attack────┘                           「橋渡し」として提示)
   (生活再建を優先)
                       E3 ──support──▶ C1
                       P1 ──support──▶ C1
                       E4 ──support──▶ C2
```

### ここで初めて見える構造（賛否リストにはないもの）

**① 同じ事実が対象主張ごとに役割を変える（evidence 設計の核）**
- **E1（1000億円・600人体制）** は **C1 を支持**（大規模投資・雇用の根拠）する一方、**C3 を攻撃**する（「雇用が人口回復に繋がらない」への反証＝600人規模の雇用は関係人口の根拠になりうる）。
- **E2（戻らない51%）** は **C2 を支持**（限られた帰還者の生活再建を優先すべき）する一方、**C1 を攻撃**する（集中投資が前提とする将来人口の見通しを弱める）。
- → 賛否リストでは E1 は「賛成の束」に固定されるが、AF では **E1 が C1 を支持しつつ C3 を攻撃する**という、文脈依存の二面性を保持できる。

**② 主張どうしの関係（未応答の攻撃）**
- C2 は C1 を攻撃している（生活再建 vs 集中投資）。これに A さんがまだ再反論していない＝**未応答の攻撃**としてグラフから検出でき、「Aさんへ：あなたの〈集中投資〉に未応答の反論〈生活再建優先〉があります」と促せる。

**③ 偏りの検出**
- C1 まわりは support（E1, E3, P1）が attack（E2）より多い＝**支持に偏っている**。反対側を補強するため、未提示の反証（例：E4 を C1 への攻撃として接続できるか）を探して出す。

**④ 橋渡しの事実**
- E1 は C1 には繋がっているが、C3（懐疑）にはまだ未接続かもしれない。その場合「E1 は C さんの懐疑（C3）への反論になります」と**対象主張へ接続提示**できる。これは外部知識を議論に取り込む動き（RQ4）。

---

## 4. 何が新規性として言えるか（先輩との差分）

| 観点 | 植田 2026（賛否2束リスト） | 本提案（統合 AF グラフ） |
|---|---|---|
| 事実のスタンス | 賛成/反対の束に**固定** | **対象主張ごとのエッジ**で相対的に付与（同じ事実が一方を支持し他方を攻撃） |
| 発話との接続 | なし（トピック単位） | 発話 claim/premise と evidence を**同一グラフで連結** |
| 主張どうしの関係 | 持たない | support/attack で連結（未応答の攻撃が見える） |
| 提示の駆動 | 「均衡的に見せる」 | **グラフ構造で介入を決める**（偏り・未応答・橋渡し・停滞） |
| 形式 | 2列リスト（静的） | 永続的な論証グラフ（リアルタイム更新） |

**要点**：先輩は「均衡的・構造化して見せる」までを示した。本提案の差分は、外部知識を
**主張に相対的な支持/攻撃の関係としてライブ議論ログに編み込み、その構造でファシリテートする**点にある。
「同じ事実が文脈で役割を変える」「未応答の攻撃」「橋渡し」は、賛否2束リストの表現力では出てこない。
