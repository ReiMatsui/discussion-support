# 人間同士ファシリテーションモード 設計計画

ブランチ: `feat/human-facilitation`

## 目的

人間2〜3人の議論を、介入エージェント単体（AIパートナーなし）でファシリテートする。
やることは本質的に3つだけ。普段は黙る。

1. **redirect** — 議論が脱線したら本題に戻す
2. **invite** — 発話の少ない人を名指しで会話に誘う
3. **none** — それ以外は黙る（デフォルト）

「良いものを作る」＝行動の種類ではなく、**タイミングと精度**（うるさくない・的外れでない）。

## 決定事項（確認済み）

- **議題**: `--topic` があればそれをシード、無ければ会議冒頭でLLMが自動推定してシード。
  （途中での議題自動更新は今回スコープ外。初回確立まで。）
- **参加度の基準**: 発話時間シェアと発話回数の**両方**をLLMに渡して総合判断。
- **積極性**: 標準。ただしパラメータ（controlled / standard / active）で調整可能にする。

## 既存の再利用（ほぼ揃っている）

- `--agent` 単体（partnerなし）でファシリテーター単体は既に動作する。
- 脱線検出: `drift_checker → drift_requests → agent_worker（単一トリガー, R2）`。
- 話者別の発話時間/回数: `records` の `ms`/`end_ms` から算出済み（HTML統計で利用中）。
- 声紋による話者識別・表示名（`disp_name` / VoiceProfiles）。
- クールダウン（`_INTERVENTION_COOLDOWN`）・状態ログ・トリガー単一化（Phase 3）。

## 設計の核（シンプル）

既存の「脱線パターン」をそのまま横展開する。新しい概念をほぼ増やさない。

- `drift_requests`（既存）に並べて `invite_requests`（対象話者付き）を追加。
- `agent_worker` が両キューを毎ループ drain し、優先度＋クールダウンで**単一トリガー**に調停。
- 実際の発話は**沈黙の“間”**で行う（人間を割り込まない）。

行動の決定は2つの軽量シグナルに分ける（決定的メトリクス＋LLMの最終判断）:
- 脱線: `check_drift`（既存）。
- 参加度: 決定的に算出した数値を軽量LLMに渡し「いま誘うべきか・誰を」を判断。

## 新規コンポーネント（最小）

### S1. 人間モードの土台＋議題シード
- `--topic 'xxx'` を追加。あれば `state.seed_topic`（Fix 8流用）で基準論点に。
- partnerなし構成（`--agent` のみ）の沈黙閾値・エコー処理を人間向けに見直し。

### S2. 参加度メトリクス（決定的・小関数）
- 直近ウィンドウ（例: 直近5分 or 直近N発話）で、話者別の「発話時間シェア」と「発話回数」を算出。
- 全期間でなく窓で見る（序盤の偏りは自然なので無視）。
- 声紋で識別済みの既知話者のみ対象。
- 純粋関数としてユニットテストする。

### S3. 冒頭アジェンダ自動検出
- `--topic` 未指定時、最初のK発話 or T秒たまったら、LLMで議題を1回推定して `seed_topic`。
- 以後は既存の論点抽出（topic_worker）が論点を育てる。

### S4. 参加度チェッカー → invite_requests → 調停
- `drift_checker` の双子として `participation_checker` を追加。
- 「明確に低い＋一定時間無発言」の候補があれば、数値＋直近文脈を軽量LLMに渡し判断。
- YESなら `invite_requests` に `{target, reason}` を積む。ウォームアップで序盤は誘わない。
- `agent_worker`: 優先度 **redirect > invite**、クールダウン共有、同一人物の連続invite回避。

### S5. プロンプト拡張＋積極性パラメータ
- invite時はコンテキストに対象話者名を渡し、「{name}さん、どう思いますか？」など短く名指し。
- `proactivity`（controlled/standard/active）を1パラメータ化。影響先はクールダウン長・
  参加度閾値・沈黙閾値。標準をデフォルト。

### S6. 実機確認・チューニング
- 2〜3人で試し、しつこさ・的外れ・割り込みの体感を調整。

## タイミング（精度の肝）

- AIパートナーと違い人間は割り込めない／割り込むと失礼。**沈黙の“間”（1.5〜3秒）に短く話す**。
- デフォルトは黙る。介入後はクールダウン。同じ人を連続で誘わない。

## 精度の守り

- **誤ターゲット**（声紋誤り/実は発言済み）→ 偏りが明確＋継続＋既知話者のときだけ、最終判断はLLM。
- **しつこさ** → クールダウン＋同一人物の連続回避。
- **脱線誤検出** → ウォームアップ＋論点品質（Fix 9/11で対応済み）。

## 進め方

S1 → S2 → S3 → S4 → S5 → S6 の小ステップ。各ステップでテストを緑に保ち、要所で実機確認。
いつでも途中でマージ可能。

## スコープ外（今は）

- 議題の途中自動更新（初回確立まで）。
- 高度なコーチング（要約の自動挿入など）は積極性 active で将来。
- AIパートナー（debate/simulate）モードは現状維持。本機能は人間モード専用。
