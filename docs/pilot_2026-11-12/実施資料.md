# 3人での試行：進行者の手順

2026年11月12日／対面3人（研究者を含む）／約30分

目的：採否の提案に対してAIが既出の理由を踏まえ、補足・訂正・異論を述べる機会を作れるかを確認する。今回だけで支援の有効性を示すことは目的としない。

始める前に：Macを電源につなぐ。3人がカメラに入る座席にする。スピーカーからAIの声を出す。Chromeを使い、API接続確認は参加者が来る前に済ませる。会話の保存先に空きがあることを確認する。

説明：「今日はシステムと議論手順の確認です。映像・音声と発言を保存します。文字起こし・AI支援を使う回は音声や発言を外部サービスで処理します。実際の就職先や個人情報を話す必要はありません。参加や録画を断ったり、途中で中止したりして構いません。データを誰がどの目的で見るかは、開始前に説明します。」

進行者は、閲覧者・保存場所・保存期間・発表利用の有無を事前に決めて伝える。今回の了承を、未説明の公開・再利用の許諾とみなさない。必要な学内手続きは所属先の扱いに従う。

0–5分：説明・了承・座席確認。
5–8分：録画だけを20秒。3人が一言ずつ話す。終了して動画を再生。
8–13分：台本確認。文字起こしが表示されてから読む。
13–15分：個別カードを読む。台本の立場は引き継がない。
15–23分：自由議論。最大8分。早く決まれば終了してよい。
23–30分：保存確認、振り返り。

操作：uv run das pilot → 了承のチェック → カメラ確認 → 設定を選ぶ → 録画と議論を開始 → 終了して保存 → 動画を開いて再生。

# 進行者：見る点と中止条件

台本確認で見ること

・明示的な採否提案を文字起こしできるか。
・AIが同じ選択肢の既出理由を、否定や条件を変えずに提示できるか。
・参加者が話し始めたらAI音声が止まるか。
・理由を扱った後、同じ内容を不必要に繰り返さないか。
・映像、3人の声、AIの声、会話ログが保存されるか。

自由議論で見ること

・採用／除外の提案が自然に出るか。出なければ0件と記録する。
・AIの直後、補足・訂正・異論が出たか。最初から人が続ける予定だったか。
・人同士の理由の検討に続くか。AIへの返答だけで終わるか。
・既に扱った話の蒸し返し、誤った引用、長い割込みがあったか。

観察記録：操作画面の「AI介入」「問題」「決定」を押す。詳細を話しながら無理に記入せず、後で動画と照合する。研究者本人の誘導・説明・操作で止まった箇所も記録する。

終了・切替

・全員の声が録れない：配置を直し、20秒確認をやり直す。
・認証エラー／本体停止：支援ありを終了。連打や繰り返し再試行をしない。
・準備が進まない：30分を使い切らず録画のみへ切替。「AI動作は未確認」と残す。
・参加者の中止希望：直ちに終了。データの扱いを本人に確認する。

次へ進む目安：台本で根拠のある介入が1回以上実際に聞こえ、全員の声と動画が再生できること。自由議論で介入が出ない場合、検出の失敗・条件の不足・機会がない状況をログで切り分ける。有意差や介入件数の多さを成功条件にしない。

# 台本確認1：既出の理由を使えるか

進行者用。台本は3人で分担して読む。自由議論とは別の技術確認である。

操作：「①台本で動作確認」「支援あり」を選び、開始する。文字起こしが表示されることを確認する。最初に「台本確認、開始です」と発声する。発言では必ず会社名を使い、「それ」「こっち」だけにしない。

1人目：「B社は毎日指導を受けられるので、実践的な経験につながりそうです。」
2人目：「まず候補ごとに特徴を確認しましょう。」
3人目：「B社は5日間かかるので、候補から除外しようと思います。」

ここだけ最大15秒待つ。これは処理を確認するための待機であり、自然な議論の介入機会の証拠として数えない。

見る点：AIがB社の除外と理由を取り違えず、先ほどの「毎日指導」を材料に補足・訂正・異論を求めるか。逐語的な同一文を正解にはしない。聞こえなければ「AI介入なし」を記録する。

AIの発話が終わったら、1人目が自然な声で続ける。既出理由がどう提示されるかを先に聞き取る。

1人目：「毎日の指導は魅力ですが、5日間を確保するのは難しいので、B社を除外することは受け入れます。」
2人目：「では指導の利点も考えたうえで、B社を除外するということですね。」
3人目：「はい、その理由も含めてB社を除外します。」

見る点：AIが利点を無条件に正しい事実として言い換えないか。理由を扱った後、同じ補足依頼を重ねないか。同一選択肢の間隔制限もあるため、繰返しがないことだけで意味理解の正確さは証明できない。

# 台本確認2：理由がない場合・撤回

時間が残った場合だけ、同じ台本試行で続ける。

ケースA：既出の理由がない採用提案

2人目：「C社を採用しようと思います。」
最大15秒待つ。

見る点：履歴にないC社の利点をAIが作らないか。一般的な補足依頼になってもよい。今回はこの動作の有用性は未確認であり、効果があるとは判定しない。

次は割込み時の停止を確かめるため、AIが話し始めたら、1人目が以下を話す。AIが出なければ15秒後に続ける。人が話し始めてAIが止まるかを記録する。

1人目：「C社は片道20分で対面参加できるので、その点を重視するなら受け入れます。」
3人目：「通いやすさを理由にC社を選ぶ、ということですね。」

ケースB：撤回された提案

1人目が続けて読む：「A社を採用しようかと思いましたが、その提案はいったん取り下げます。まだA社に決めるつもりはありません。」

見る点：撤回後にA社の採用を促す介入をしないか。途中で介入した場合、発言のどこまでが入力されていたかを後でログで確認する。

終了：画面の「終了して保存」を押し、保存完了を確認する。次の自由議論は別の試行として開始する。台本で発言した立場は引き継がない。

台本の結果メモ
既出理由：正しい／誤り／提示なし
音声停止：止まった／止まらない／確認できず
理由なし：補足依頼／内容を創作／提示なし
撤回：介入なし／介入あり／確認できず
