# 研究設計 第5版（2026-10-05）

第4版と第5版初稿を、三つの立場の査読役に二巡かけた結果である。立場は社会心理の方法論、HCI の新規性と実装、両先生の視点。数値の多くは要約経由で読んでいるので、引用前に原典で照合する。

## 1. 一文で

対面の3人の議論で、一人が出した情報が誰にも拾われずに流れたとき、エージェントがその情報を、別の人が前に言ったことと結びつけて一度だけ声で問う。ただ言い直すだけの問いと比べて、他の人がその情報に判断を下すようになるかを確かめる。

## 2. 課題

AI に進行させると情報は出るが、他の人に処理されず、決定は良くならない（Alsobay ら CSCW 2026、Zercher ら 2025、Lee ら ICWSM 2026、Parisi ら FAccT 2026）。対面の声は数秒で消え、読み返せない。対面の音声の先行システムは時間と発話量を扱い、内容を扱っていない（Mukhopadhyay ら CHI 2026、西村ら）。

## 3. 問い

対面の3人が案を一つ選ぶ議論で、一人が出して拾われなかった情報について、別の話者の発言と結びつける問いは、本人の名を添えて言い直すだけの問いと比べて、他の二人による理由つきの判断を増やすか。

成功は判断が起きたことである。採用でも却下でもよい。決定の質は主張しない。

## 4. 最も近い先行研究と違い

最も近いのは Academically Productive Talk のエージェントである（Dyke ら 2013、Adamson ら 2013/2014、Tegos ら 2015）。拾われなかった発言について「Xさんの考えをどう思いますか」と問う。文字のチャット、学習場面、定型の問い。

同じ研究室の系譜では D-Agree と Dong, Ding & Ito 2024。オンラインの文字、構造の抽出と段階の制御。

違いは三つ。

1. 問いの中身。離れた二つの発言を、話者をまたいで結ぶ。相手の発言は、それまでの全発話から LLM が推論で探す。項目表にない目標、制約、懸念も対象にする。
2. 場。対面の声で、卓上マイク1本から話者を特定して名前を添える。
3. 評価。結びつけの有無そのものを、セッション内で無作為に割り当てる。

先行の型を対照条件に置くので、違いが効くかどうかを直接確かめられる。

概念は情報精緻化（van Knippenberg ら 2004、Homan ら 2007、Mell ら 2014）を使う。事後の符号化の基準として使い、設計のすべてを決める枠組みとは言わない。多様性研究が出どころであること、信頼性の値が集団合計のものであることは明記する。

## 5. 提案手法

1. 聞き取り。発話を課題の項目表に照合し、話者をつける。並行して、各話者が述べた目標、制約、懸念の一覧を LLM が保つ。
2. 拾われたかの追跡。一人だけが出した項目について、他の人が実質的に取り上げたかを二値で持つ。質問、結論づけ、理由つきの却下、他の情報との結合を取り上げとする。相づちは数えない。
3. 対象の決定。機械的に決め、どの項目かに LLM の裁量を入れない。条件は、出したのが一人、W 秒以内に取り上げなし、その後に別の話題で他の人の実質的な発話が二つ以上、まだ収束していない、問いが上限未満。W は試行で測った取り上げまでの時間の80パーセンタイル。
4. 相手の探索。対象になった項目すべてについて、別の話者の過去の発言から関係するものを LLM が探す。関連の強さだけで選び、どの案に有利かでは選ばせない。正解は LLM に伏せる。見つからなければ、同じ観点の他の案の情報を表から引く。
5. 承認、その後に割り当て。操作者が問いの案をキー一つで承認か却下する。編集はできない。承認の後で、結びつける問いか、言い直すだけの問いかを無作為に決める。両条件が同じ人手の確認を通る。
6. 発話。全員に向けて一文、一度だけ。
   - 結びつける問い：「Cさんの、B案は納期が3週間という話は、Aさんの年内に動かしたいという話と合わせると、案の評価にどう関わりますか」
   - 言い直すだけの問い：「Cさんの、B案は納期が3週間という話は、案の評価にどう関わりますか」
   
   二つの問いは結びの句を同じにし、違いを相手の発言の有無だけにする。操作者は両方の文を見て承認する。途中で遮られた問い、期限切れ、取り下げも、割り当てどおりに分析に入れる。
   
   含意は言わない。評価しない。繰り返さない。追いかけない。
7. 出し方。問いが待機中であることをランプで示す。発話の切れ目で話し、期限を過ぎたら捨てる。期限は試行で決める。最後の問いの一文だけ画面に残す。一覧も図も出さない。事前に、問いは最大5回で各一文、「いまはいい」と言えば取り下げる、と伝える。

正式な運用は操作者の承認つきとする。全提案を記録し、全自動だった場合の精度は別に報告する。

### 対面、LLM、話者つき音声認識がそれぞれ要る理由

- 対面。読み返せないので、数分離れた別の人の発言どうしの関係は、聞き手が最も落としやすい。
- LLM。続く発話が実質的な取り上げかの判定と、関係する過去の発言の探索。後者は表引きではできない。これは下の検証で確かめる。
- 話者つき認識。出したのが一人であること、相手が別の話者であること、二人の名前を添えること。

## 6. 評価

### 6.1 設計

3人×5組×同型の課題2つで10セッション、各約20分。3案、約24項目、一人だけが持つ標的項目を8〜12。標的には正解を支持するもの、囮を支持するもの、中立のものを混ぜる。

課題には役割ごとの目標と制約を持たせる。例は、年内に動かしたい、予算の上限がある、など。項目表の外に結びつけの相手が生まれるようにするためである。

議論の前に、各自が各案を0〜100で評定する。一つを選ばせない。資料は議論前に回収する。参加者には仮説を伝えない。課題の順序は入れ替え、報告する。

### 6.2 比較

単位は対象になった項目。セッション内で、結びつける問いと言い直すだけの問いに無作為に割り当てる。見込みは各条件20〜25項目。

上限を超えて問いが出なかった項目と、エージェントなしの試行は、何もしない場合の参考として記述する。無作為の比較には入れない。

### 6.3 指標

主要指標は一つ。問いの後60秒以内に、持ち主以外が、その項目がどの案にどう効くかを述べたか。二つの発言の関係を述べただけの応答は別に数え、主要指標には入れない。書き起こしを二人が符号化する。応答に相手の発言が出てくるので、条件を完全には伏せられない。これは限界として書く。

結びつける問いでは、名前を呼ばれた相手に答える義務が生じる。持ち主でも相手でもない三人目の応答を分けて集計し、これを最も交絡の少ない検証とする。

結びつける問いは、LLM が選んだ相手の場合と、表引きの相手の場合を分けて報告する。

副次指標。

- 判断の中身。採用、却下、他の情報との結合の別。
- 議論後の個人テスト。持ち主以外に、その項目がどの案にどちら向きに効くかを答えさせ、課題の正解表で採点する。偽の項目を混ぜる。自分で考慮したかも聞く。
- 問いのやり取りを除いた後の、自発的な再利用。最終の理由への登場。
- 中立の項目でも同じ効果が出るか。出るなら目立っただけである。

### 6.4 分析

セッションで層別した並べ替え検定を事前に登録する。項目の中に持ち主以外が二人入る構造を扱う。区間推定を添える。検出力は低い。査読役の見立てでは主要指標で差が出る見込みは高くない。差が出なくても成り立つよう、記述の結果の最低線を先に決めておく。

### 6.5 LLM の段の検証

録音の中の対象の瞬間すべてについて、LLM が選んだ相手と表引きの相手を、出どころを伏せて三人が評定する。関連性と中立性。選ばれた相手がどの案に有利かの分布と、問いの文が含意を言ってしまっていないかを監査する。表引きに落ちた割合を報告する。

### 6.6 場の記述

- 問いに集団が何をしたか。取り上げた、退けた、エージェントを訂正した。
- 最初の問いの前と後で、問いの対象でない項目の取り上げが変わるか。1回目と2回目のセッションで変わるか。エージェントが場の規則を変えたなら、ここに出る。
- 誰が誰の情報を拾ったか。エージェントが占めた発話の割合。議論前後の評定。
- この仕組みで見えないもの。感情、語り、関係。実例で示す。

### 6.7 妥当性

項目照合、取り上げの二値判定、話者同定を、人手の符号化と比べる。貢献ではなく妥当性の節に置く。

第三者評価は、エージェントの発話を取り除いた抜粋で行う。

## 7. 作る前の試行と中止基準（第1週）

| 試行 | 測るもの | 中止基準 |
|---|---|---|
| 紙のみ、2組 | 対象になる項目の数、取り上げまでの時間 | 1セッション平均4未満なら標的を12に増やす。それでも足りなければ課題を替える |
| 人がエージェント役、2組 | 二種類の問いへの反応、発話までの遅れ | 半分以上が無視されるなら、実装前に文を作り直す |
| 同じ録音 | 項目表の外に相手が見つかる割合 | 3割未満なら役割の目標と制約を増やす |
| 紙の規則のみ、1組 | 決める前に各自が流れた点を一つ挙げる、という規則でどうなるか | なし。なぜ AI かに答える材料 |
| 録音でオフライン検証 | 照合と取り上げ判定の精度 | 適合率8割未満でも操作者承認で続行 |

## 8. 貢献

1. 対面の AI 進行の介入原理。流れた情報を、別の人の過去の発言と結ぶ一文の問いで戻し、判断は集団に残す。
2. 結びつけが言い直しより効くかの、10セッションでの無作為比較と、場の記述。
3. LLM が選ぶ結びつけが表引きより良いかの検証と、マイク1本の話者つき認識で何が支えられるかの実測。

## 9. 両先生への対応

| 指摘 | 対応 |
|---|---|
| 伊藤先生：新規性 | 最も近い先行の型を対照条件に置き、違いを直接比べる |
| 伊藤先生：タイミングでなく内容 | 操作する変数は問いの内容だけ。タイミングは両条件で同じ |
| 伊藤先生：一歩先 | 項目表の外の発言を相手に選ぶ部分。表なしの抽出は考察で扱う |
| 伊藤先生：第三者評価 | エージェントの発話を除いた抜粋を外部の評定者が見る |
| 谷口先生：問いが散漫 | 問いは一つ。精度は妥当性の節へ |
| 谷口先生：個体でなく場 | 主要指標は他の成員の振る舞い。問いの対象外の項目への波及を場の結果として報告 |
| 谷口先生：何が明らかになるか | 流れた情報が判断されるかどうかは、結びつける問いで変わるか。集団はその問いに何をするか |

集合的予測符号化との関係は、考察での解釈にとどめる。

## 10. 残る弱点

- 項目表が要る。実際の会議では自由な抽出が必要になる。
- 操作者の承認つきである。
- 取り上げの判定を見逃すと、済んだ話を問い直す。日本語は省略が多く、反応の瞬間は発話が重なる。実装で最も危うい部分である。
- 何もしない場合との比較は無作為ではない。
- 切れ目が少ないと問いが遅れ、話題が移る。
- 件数が少ない。知り合いどうしである。
- LLM による相手の選択は裁量であり、誘導の余地が残る。監査はするが消えない。
