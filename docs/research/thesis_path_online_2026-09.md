# 対面実験なしで修士論文を書ける形にする方針（2026-09-10）

> 問い: 対面の参加者実験がすぐに用意できない。オンラインで完結する方法で、
> 修士論文を書ける状態まで持っていけるか。音声側に全面シフトして
> 「新しいモデルを作り精度を示す」のは無理があるか。
> 前提: 中間試問会の原稿（docs/abstract）で約束した内容、STATUS.md の数字、
> 7月のマスタープラン（research_masterplan_2026-07-07.md）を踏まえる。
> 提出は 2027年1月末〜2月と仮定（残り約4.5ヶ月）。

## 1. 結論

対面実験を前提から外しても、修士論文は書ける。ただし「音声側に全面シフトして
新しいモデルで精度を競う」形ではなく、次の3本柱に組み替える。

1. 選択的話者同定の評価を厚くする（公開コーパスの本数を増やし、確信度を
   学習で求める版を加え、棄権の効果を risk–coverage で示す）。すべてオンラインで
   完結する。論文の中核はここ。
2. 名指し介入の効果と誤名指しのコストを、オンラインの視聴実験で測る
   （原稿8.1節の視聴実験をそのままウェブ実験にし、人数を10〜15名から
   60〜100名に増やす）。介入側の主結果はここ。
3. ライブ実験は「できれば」に格下げし、対面でなくオンライン会議（Zoom等の
   混合音声をシステムが聴く形）でも成立する設計にしておく。2〜3グループの
   パイロットが取れれば章にし、取れなければ限界として書く。

この形なら、対面の準備が一切できなくても12月に全章の初稿が書ける。対面が
できた場合は3の章が厚くなるだけで、構成は変わらない。

## 2. 「音声側に全面シフト」の評価

無理があるのは「新しい話者分離・声紋モデルを訓練して既存手法より高精度を示す」
という形で、理由は3つある。相手が NVIDIA（Streaming Sortformer）や pyannote で、
訓練データ・計算資源・人月のどれも4ヶ月で並ばない。標準ベンチマーク（AMI 等の
DER/cpWER）で比較されるので、負ける土俵に自分から乗ることになる。中間試問会で
「介入のための同定」と位置づけたばかりなので、介入を落とすと研究の動機が消え、
指導教員の分野（合意形成・議論支援）からも外れる。

一方で、音声側を「厚くする」のは有効で、次の形なら新規性も守れる。

- 貢献の言い方を「実時間の実名話者同定における選択的予測（selective
  prediction）」にする。棄権つき予測は機械学習で確立した枠組みで、
  risk–coverage 曲線（名前を出す割合と、出したときの誤り率の関係）で示せる。
  原稿の表3（被覆と名指し中の正しさ）はすでにその1点なので、閾値を動かして
  曲線にするだけで章が一つ立つ。
- 「新しいモデル」を作るなら、話者分離や声紋ではなく**確信度の推定器**にする。
  今は3つの証拠（文字ラベル・声の区別・声の照合）を手で決めた閾値で
  突き合わせているが、これを発話ごとの特徴（各証拠の一致、類似度、発話長、
  経過時間、席の状態など）から正誤を予測する小さな分類器（ロジスティック回帰
  や勾配ブースティング）に置き換え、会話単位の交差検証で手法の規則版と比べる。
  データは正解つき13会話＋千葉12会話＋AMI で、発話数で数千。過学習の
  危険はあるが会話単位で切れば防げる。これは「学習で確信度を求めても規則版と
  同等以上か」という問いになり、答えがどちらでも書ける（同等なら規則の
  妥当性の証拠、上回れば改善）。
- 公開コーパスの本数を増やす。AMI は1会議しか測っていないので、テストセット
  16会議に広げると英語側の主張が「1本の確認」から「標準セットでの値」になる。
  日常会話コーパスも正解付けを数本足す（1本20〜30分の注釈）。

これらは全部、手元の録音と API だけで進む。対面の準備は要らない。

## 3. 介入側をオンラインで完結させる方法

### 3.1 視聴実験のウェブ化（本命）

原稿8.1節の設計をそのまま使う。録音済みの3人議論から2〜3分を6区間切り出し、
末尾に合成音声の介入を重ね、（A）正しい名指し・（B）宛先なし・（C）誤った名指し
の3水準で、有用さ・タイミング・「議論を把握しているか」・受容を7件法で評定する。

変えるのは実施形態だけで、ブラウザで完結するページにし、参加者を研究室外から
集める（クラウドソーシング、あるいは学内募集）。人数を60〜100名にすると、
AとBの対比（宛先の効果）、AとCの対比（誤名指し1回のコスト）、Cの後続への
持ち越し（信頼毀損の持続）のそれぞれに、小標本では出ない区間推定が付く。

必要なもの: 倫理手続き（匿名のウェブ質問紙は迅速審査になることが多い。
9月中に申請）、刺激（既存録音＋TTS。原稿の設計どおり）、実験ページ
（回答をサーバに保存する静的ページで足りる）、謝礼の予算。

これが取れれば、介入側の主結果は「名指しという宛先の効果と、誤名指しの
コストの定量」になり、対面がなくても「誰に」の軸に答えたことになる。

### 3.2 ライブ実験を対面からオンライン会議へ

参加者実験（H1 応答率・H2 発話量）を、対面ではなくオンライン会議で行う案。
Zoom や Meet の混合音声を仮想オーディオデバイス（BlackHole 等）でシステムに
流し、介入音声を会議に返す。システムは会議プラットフォームの話者情報を使わず
混合音声だけから同定するので、第1段の前提（音声だけで誰が言ったかを得る）は
保たれる。会議室・機材・参加者の移動が不要になり、録音も自動で残るので、
準備の負担が対面より格段に小さい。

代償は、論文の主張を「対面」から「音声のみで話者を判別する必要がある議論
（対面・ハイブリッド・録音）」に広げて書き直すこと。序論の動機は対面のまま、
評価はその近似として行ったと限界に明記する。指導教員に先に相談する。

### 3.3 補助的にできること（章にはならないが、論文を支える）

- LLM エージェントによる議論のシミュレーション（`--simulate` と7月の
  シミュ実験基盤がある）で、「いつ・何を」の機構を確認する。人間の効果の
  証拠にはならないので、7月の方針どおり「シミュ＝機構確認」として使う。
- 既存録音に「介入すべき箇所」を注釈し、沈黙・偏り・脱線の検出器を採点する。
  「いつ」の軸を、参加者なしのオフライン検出課題として扱える（When2Speak と
  同じ問題設定）。1章分の分析にはなる。
- 感度分析（原稿6.3節）は既に「誰に」の一部（同定の誤りが名指しに乗る量）を
  参加者なしで答えている。

## 4. 論文の構成（対面なしで成立する版）

1. 序論: 対面議論支援、3条件、いつ・誰に・何を
2. 関連研究
3. 要件と問い
4. 選択的話者同定（現行）
5. 同定の評価（現行＋AMI拡張＋学習版の確信度＋risk–coverage）
6. 介入の設計と同定誤りの影響（感度分析。現行）
7. 名指し介入の効果と誤名指しのコスト（オンライン視聴実験。新規）
8. ライブ実験（オンライン会議または対面のパイロット。取れた分だけ）
9. 考察・限界・結論

7章までで論文として閉じる。8章は補強。

## 7. 判断を仰ぐ点

- 指導教員に、対面をオンライン会議で代替する案（3.2）と、視聴実験の
  規模拡大（3.1）の2点を相談する。前者は主張の言い直しを伴うので早いほどよい。
- 視聴実験の倫理手続きの経路（学内の様式・迅速審査の可否）と、謝礼の予算。
- 確信度学習を「新規性」として前に出すか、「規則版の妥当性の確認」として
  控えめに出すか。結果を見てから決めてよいが、序論の書き方が変わる。
