# 支援内容が悪い場合と対象選択が悪い場合の切り分け、継続・変更・撤退の基準

## 1. 切り分け

提示ごとに、録画を見た人（第2符号化者。提示した研究者以外）が `04_符号化表.csv` の3列を付ける。

- content_accuracy（提示の正確さ）
- target_selection_ok（対象選択）
- timing_issue（時期）

| 観察 | 内容の問題 | 対象選択の問題 | 時期の問題 | 形式・必要性の問題 |
|---|---|---|---|---|
| 参加者が提示の帰属を訂正した（「そうは言っていない」） | ○ | | | |
| 提示の時点で、前提は既に話されていた | | ○ | | |
| 前提の違いは、実際にはなかった（符号化者の判断） | | ○ | | |
| 提示が発言を遮った、または決定後だった | | | ○ | |
| 正確で、対象も正しく、時期も問題ないのに、無視された・邪魔とされた | | | | ○ |
| 正確で対象も正しく応答はあったが、その後の理由づけに使われなかった | | | | ○（必要性への疑い） |

- 内容と対象選択の両方に問題がある提示は、どちらの評価からも外して、別に数える。
- 研究者の判断記録の「迷った点」は、対象選択の難しさとして別に集計する。自動化する場合に必要な判定の手がかりになる。

## 2. 継続・変更・撤退の基準（試行の前に決めておく）

形成的な試行なので、数値の合格基準は置かない。次の観察のどれに当たるかで判断する。基準はこの版で固定する。試行の後に変えた場合は、変えたことを記録する。

### G1（支援なし）の後に判断する

| 判断 | G1 で観察されたこと |
|---|---|
| 継続 | 2人以上が前提の違う理由を述べ、どの前提で選ぶかを明示的に話さないまま決定した場面が1回以上ある |
| 変更（課題を見直す） | 前提の違う理由が出なかった（全員が同じ前提で話した）。課題の情報が前提を事実上固定していないかを見直し、1集団だけ追加で試す |
| 撤退 | 前提の違う理由は出たが、参加者が自力で早く（開示の後すぐ）前提を明示し、そろえた。支援の必要が観察されない |

### G2・G3（研究者による提示）の後に判断する

| 判断 | 観察されたこと |
|---|---|
| 継続（自動化の検討へ） | 正確で対象も正しい提示に対し、2集団のうち少なくとも1集団で、前提を選ぶ・両方に備えるといった応答があった。その前提がその後の理由づけか決定の理由に使われた。面接で強い負担の訴えがない |
| 変更（提示の形・時期を変える） | 対象選択と内容は正しかったが、時期の問題か形式の問題（無視、邪魔）が中心だった |
| 変更（対象選択を見直す） | 対象選択の問題（既に話されていた、前提の違いがなかった）が、提示の半分以上を占めた |
| 撤退 | 提示に応じても、前提がその後の判断に使われなかった。または提示の後、人どうしの検討が AI への応答で置き換わった（応答が画面への返答だけで終わる）ことが、両集団で繰り返された |

### G4（静的カード）の後に判断する

| 判断 | 観察されたこと |
|---|---|
| 静的な手段に切り替える | カードによって、G2・G3 と同じ程度に前提が明示され、判断に使われた。この場合、研究の中心を「実時間の提示」から「議論手順の設計」に移す。AI を使う理由は、発言から前提を拾うこと（カードにない前提）に限られる |
| 実時間の提示を続ける | カードは使われなかった、または課題で予想した前提以外の前提が重要だった |

## 3. この試行で言わないこと

- 決定の質や正答率の改善（正解のない課題で、3〜4集団しかない）。
- 自動介入の有効性。
- 観察された頻度を、自然な議論の頻度として一般化すること（課題は前提によって最良案が変わるように作ってある）。
