## やること

1. 全ターンを、選択事項または局面ごとの区間に分ける（すべてのターンがどれかの区間に入るように）。
2. 区間ごとに少なくとも1つの事例を書く。困難がない区間は「困難なし区間」として1件書く。
3. 次の種類の事例を、見つかる限り偏りなく拾う。
   - 困難
   - 有用な行為
   - 人が自力で解消
   - 他者の働きかけで前進
   - 停滞に見えて問題なし
   - 再検討せず合理的
   - 判断不能
4. 各事例の引用は原文のまま短く、ターン番号を付ける。解釈と別の解釈を必ず書く。内面は推定と明記する。
5. 「返答なし＝理解していない」「短い発言＝不参加」「反復＝無駄」とは判定しない。
6. 分類 v1 に当てはまらない行為や困難が繰り返し出た場合は、無理に当てはめず、`new_code_proposals` に書く（名前、説明、該当ターン）。

- case ID は "{M}-X01" から通し番号。
