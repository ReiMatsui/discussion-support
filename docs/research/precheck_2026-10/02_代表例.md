# 代表例

発話は元データの原文のまま載せる（英語）。ターン番号は前処理後の番号で、元の発話 ID は `candidates_all.csv` の ground_source_ids 列にある。時刻は元データの値。比較案と訳は判定者（AI）が書いたもの。「後続」は候補を固定した後に開いた発話で、AI への応答ではない。

出典: GAP コーパス（Braley & Murray 2018、CC BY-NC 4.0）、AMI 会議コーパス（CC BY 4.0）。

## 1. 成立例（妥当そうで、後続に実質的な更新の情報が出た）: GAP08-C5（7位の品目）

候補時点までの会話:
```
[t119 219.2s Orange] I had rope $
[t120 220.2s Green] I had the chocolate bar cause you know we need food
[t99  183.5s Blue]  I think rope always comes in handy  I cant think of a need for rope right now ...（根拠として参照）
[t45  76.0s Blue]   If no ones coming to find you And that takes like three days（根拠として参照）
```
比較案（t121 終了時点）:
> チョコは食料、ロープは使い道がまだ具体的でない、という状況です。救助が来ず3日歩くなら、食べ物とロープのどちらが先に要る場面を想定しますか。

判定の内訳:

- 未確認の条件: ロープを使う具体的な場面、移動するか待つか
- 人間が既にしている比較: なし
- 品質: 8項目とも満たす（J1・J2）

後続（固定後に開いた発話）:
```
[t130 237.1s Orange] How come you put rope so much later Just cause you cant think of a use for it
[t131 239.4s Green]  ... were in um a forest like in the woods with lakes and rivers So Im not sure if were actually going to need to climb anything
[t132 251.7s Blue]   What if you need to make like a boat or shelter
```
分類は次のとおり。

- S3（新しい根拠で比較の意味が変わる）: 10ターン後
- 問いへの答え: 出た
- 更新: 実質的
- 決定: t147（ロープに決定）

観測された情報を入力した場合のオフライン動作例（AI による作例。実際の会話には AI はいない）:
> ロープは湖を渡るいかだやシェルターを組むのに使え、チョコは食料です。3日歩く間に、湖を越える場面と食べ物のどちらを重く見ますか。

読み方: 比較案の前提（ロープの使い道が具体的でない）は、人間どうしの会話の中で崩れた。AI の問いに答えて崩れたのではない。

## 3. 生成不能例

### 3a. 方針Bのチェック時点で材料がない: ES2004c-B180（180秒）

```
[t23 173.3s B] and we were gonna think about the port and an alarm for getting it lost,
[t25 178.1s B] things like that, um and our market was going to be young, business, kind of range.
[t27 188.6s B] Okay, so shall we start with the first presentation?
```
判定は生成不能だった。理由は「前回決定事項の確認中で、開いている選択事項がない（充電池は調査予定と述べられただけで、選択肢・根拠なし）」。

### 3b. 二択として成り立つか不確か: GAP18-C5（6位に拳銃を置くか）

```
[t103 278.5s Blue]  I said the loaded caliber pistol yeah
[t105 282.6s Blue]  For like hunting and stuff maybe
[t106 283.4s Orange] Me too
```
- 生成可能: 不確か
- 提示が妥当そう: 不確か
- 理由: 対抗する品目がまだ出ておらず、「採用する／しない」の二択として扱うか迷う。Pink が自分の6位を言う直前でもある。

後続では、t107 に新聞が対抗として出て、t119 で拳銃6位・新聞7位に決まった。理由（狩りが要るほど長くいるか）は話されなかった。

## 5. 控えた例（人間の検討中）: ES2003c-C5（チップ）

```
[t55 384.8s D] ... it requires a more expensive chip to use, and if you wanna use L_C_D_ it's even more expensive. So you have to decide
[t57 452.6s D] Yeah. So, depends where gonna spend the money if you want the f fancy L_C_D_ display.

```
- 判定: 生成可能。ただし提示は控える（H2: 費用差についての質問に回答待ち）。
- 後続: t72 で予算12.5ユーロが分かった。t82 でデザイナーが、通常電池と単曲面にすれば LCD と高いチップを載せられると、自分で配分を比べた（S1: 24ターン後）。

AMI では、このように発表や質疑の途中で材料がそろい、その後は人間が自分で比べる流れが多かった。

## 6. 品質の問題例（参加者の主張を事実として断定）: GAP08-C4（6位）

```
[t101 193.4s Green] I had the cigarette lighter but it was because it has the flint inside of it And even if it doesnt have fluid you could still make a fire
```
比較案:
> ライターは燃料がなくても火打ち石で火が起こせ、5位で迷っている火の手段にも関わります。ロープは何に使う場面を想定していますか。

品質評価の結果:

- 項目2（未確認の条件を断定しない）: 満たさない（J1・J2）。Green 一人の見立てを、帰属なしで事実として言っている。
- 項目7（一方を有利にしない）: 満たさない。

文面は「Green さんは、燃料がなくても火打ち石で火を起こせると言っていました」のように、帰属を付けるべきだった。
