## 2. 表現の変更

- 「読み返すだけ」「単なる書記」「閉じ方を預かる」「閉じる権利を預かる」「決定の引き受け手」「議長ではなく書記」は使っていない。資料名も「選択肢の記録と確認」に戻した。
- 「AI」は「LLM エージェント」「エージェント」に統一。
- 「仮除外」「仮に外して進める」「確定します」「保留にします」というエージェントの発話は削除（下記 3 の設計変更による）。
- 「記録します。付け足しがあれば今どうぞ」→「記録しました。補足や訂正があればどうぞ」。

## 3. 設計の変更（元資料と意味が変わる箇所）

| 元資料の記述 | 更新版 | 理由 |
|---|---|---|
| 段 2: 理由つきで同意 →「確定します」、「うん」か無応答 →「一旦外して進めます」 | 無応答では記録を変えない。一人の賛成は賛成した発言として記録するだけで、除外の成立や確定は宣言しない | エージェントが記録する発言と、参加者が成立させる決定を区別する。無応答や一人の賛成から集団の決定を確定しない |
| 段 2: 異論が出た →「両方記録して保留」 | 異論は異論として記録する。集団として保留を決めたことにはしない | 異論の記録と、集団としての保留の決定を区別する |
| （訂正の扱いは未記載） | 抽出誤りの訂正（エージェントの解釈の訂正）と、提案の撤回（参加者の意思の変更）を別に記録し、別に数える | 評価指標（訂正の負担、不要な確認）で区別が必要 |
| 段 3: 「C は外す理由が出ていません。確定でいいですか」 | 最終確認は、理由や異論の記録がある選択肢の状態を一度だけ読み上げる。どの案にするかは言わず、確定も求めない | 閉じる判断を参加者に残す |
| 「対面の音声には痕跡が残らず、消えた選択肢に戻れるのは数秒だけ」 | 「実時間の音声議論では、発言が続く中で以前の理由を参照し直しにくく、理由の補足や確認がないまま次の候補へ進む可能性がある」 | 数秒という断定の根拠がない。対面で他の媒体より頻繁に起きるとも主張しない |
| 「選好に合わない理由は、他者が声に出して認めたときだけ決定に効く」 | 「他の参加者が声に出して認めた条件で決定の変更が増えた」。必要条件とは書かない | Mojzisch ら 2008 は必要条件を示していない |
| 「足りないのは情報ではなく、出た理由への応答」 | 「情報が共有されることと、理由が検討され判断に使われることは別の過程」。Alsobay らの原因は特定しない | 著者が機構を特定していない |
| 「提案は『うん』で理解と同意まで進み、拘束に至らないまま放置される」 | 「短い肯定の応答だけではそれ（commitment）が表れないことがある」 | Stevanovic は短い応答が一般に曖昧だとは述べていない |
| 「対面支援システムの 20 年の研究は…この閉じ方に介入した例はない」 | 「調べた範囲では同じ設計は見つからなかったが、不在の証明ではない」 | 断定を避ける |
| 新規性: 「決定の瞬間を内容理解で捉えて音声で介入する対面システム」 | 対面・音声・LLM・記録は単独では新規性にしない。差分は、提案に対応して理由を確認し、補足・訂正の機会を会話の進行中に設けること | 新規性を媒体や技術で説明しない |
| 発言なく消えた選択肢（「Bは却下されないまま消える」）への対処として説明 | 介入の対象は明示的な外す・残す・選ぶ発言に限る。発言なく消えた選択肢の検出は行わない | 明示的な発言への介入と、消えた選択肢の検出を混同しない |
| 「発話は定型文に引用をはめるだけで生成を含まない」 | 引用の実在検査は文字列の実在を保証するだけで、種別や対応付けの意味の正しさは保証しないと明記 | 引用が実在することと意味を正確に扱えることを分ける |
| ボタン発火版、実験者による発火確認 | 削除 | スライド v2 以降で不採用 |
| 評価: 「選択肢の閉じられ方（理由あり除外・理由なし除外・消失）」「戻す権利は使われるか」 | 理由への応答、判断への接続、負担と副作用（時間、中断、訂正負担、追認の圧力）。正答は補助指標 | 成果を人の理由の扱いと判断への接続で測る |
| 6〜8 グループ、18〜24 人 | 組数は募集次第で未確定 | 未確定のまま記載 |

## 4. 文献の修正

- 岩谷・村本 2015（事後の説明が選好に合わせて変形する）: 主張を支持しないため削除。
- Mukhopadhyay ら 2026（内容を提案する音声割り込みは成績を落とす）: 一般化できないため削除。

- Thürmer ら 2015: 統制条件にも見直しの指示があったことを追記。「42 群」ではなく「0/42 対 5/42 決定」。

- Meeting Mediator などの発話量フィードバック系: 新規性の表から外した（採用しなかった案として本文には残さない）。
