# GPT-Live の影響評価と対応方針 (2026-07-09)

> 作成: Claude Fable 5 (claude-fable-5), 2026-07-09

## GPT-Live とは（2026-07-08 発表）

- **全二重（full-duplex）音声モデル**: 聞くと話すを同時に行い、「話す/聞き続ける/一時停止/割り込む/ツール呼び出し」の対話判断を毎秒複数回実行。相槌（mhmm等）、間の尊重、自然な割り込み対応がモデルネイティブ。
- **委任アーキテクチャ**: 会話担当（GPT-Live）と深い処理（背後の GPT-5.5、検索・推論・エージェント作業）を分離。処理中も会話を継続。
- **提供状況**: 現在 **ChatGPT のみ**。API は「近日提供」でフォーム登録のみ（2026-07-09時点で利用不可）。
- 同時期に **gpt-realtime-2.1 / 2.1-mini が API で公開済み**（7/6）: 割り込み挙動・無音/ノイズ処理の改善、reasoning effort 設定、キャッシュ割引。

## 本システムへの含意

### 1. ロジック簡素化の可能性（API提供後）
本システムで最もバグが集中している層（コードレビュー07cのA-1/A-2/A-6）は、まさに全二重モデルがネイティブに解決する領域:

| 現在の自前実装 | GPT-Liveでの扱い |
|---|---|
| barge-in判定（8文字閾値＋相槌regex＋ai_speakingゲート） | モデルが毎秒複数回判断 |
| graceful yield（300ms残し）・truncate処理 | ネイティブの譲歩挙動 |
| エコー安全網（テキスト類似度0.35） | 全二重前提の音響設計 |
| 沈黙タイマー（15s/8s/None のプロファイル） | 「間」の自然な解釈 |

移行すれば `_workers.py` の割り込み系・`_realtime.py` の interrupt 機構の大半を削除でき、07cの高優先バグ群は構造ごと消滅する。

### 2. ただし修論スコープでは乗り換えない（推奨）
- **API未提供**: 時期未定。10月に対面本実験＝システム凍結のスケジュールと両立しない
- **多人数対面は想定外の可能性**: GPT-Liveは1対1会話向け設計。話者帰属（誰が言ったか）は自前（Soniox＋声紋）が引き続き必要
- **実験統制の喪失**: 本研究は「いつ・誰に・何を介入するか」をControllerで統制し、条件比較する設計。介入タイミングをモデル任せにすると、C3の主張（what/whom=AF、when=会話物理の二層分離）と実験の再現性が崩れる
- 途中でのアーキテクチャ変更は実験条件の同一性を破壊する

### 3. 研究上はむしろ追い風（考察・関連研究に使う）
GPT-Liveの「会話担当と深い処理の分離」は、本研究の**二層分離設計（when=会話物理／what・whom=AF）と同型**。業界のフロンティアが同じアーキテクチャに収斂したことは、設計の妥当性を支持する外部証拠として序論・考察に引用できる。「全二重モデル上でのAF介入」は今後の課題節の有力な1項目。

## 推奨アクション

1. **今すぐ・低リスク**: `OPENAI_REALTIME_MODEL=gpt-realtime-2.1` を試す（現在 `gpt-realtime-2`、環境変数のみで切替可能）。割り込み挙動・無音/ノイズ処理の改善は07cのA-1/A-6の症状を実地で緩和しうる。スモークテスト（セルフドライラン）で確認してから採用。コスト面では 2.1-mini（audio out $20/1M vs 2.1 $64/1M）も比較候補
2. **登録だけ**: GPT-Live-1 API の通知フォームに登録（https://openai.com/form/gpt-live-1-in-the-api/）
3. **修論**: アーキテクチャは現行のまま凍結。GPT-Liveは (a) 関連研究/考察で二層分離の収斂として引用、(b) 今後の課題「全二重モデルへのAF介入の移植」として記述
4. **修論後**: API提供され次第、割り込み系ロジックを大幅削減した v2 アーキテクチャ（GPT-Live=会話、AFパイプライン=委任先）を検討

## 補足: API提供時の影響詳細（2026-07-09 追記）

- **消える層**: barge-in判定・graceful yield・エコー安全網・沈黙タイマー群（`_workers.py`/`_realtime.py` の会話物理 約1,500行相当）。07cレビューの高優先バグA-1/A-2/A-6は問題ごと消滅
- **残る層**: AFパイプライン全体、Controllerの what/whom 判断、話者帰属（GPT-Liveは1対1向けで話者識別の保証なし）、評価系
- **難しくなる層（v2移行可否の判定基準）**: 全二重モデルは自律的に相槌・割り込みを行うため、(a) 条件間の介入頻度統制、(b) 介入タイミングの決定性・ログ可能性、(c) 積極性プロファイルという操作変数、が失われる恐れ。**v2検討の最初の実験は「プロンプト指示でどこまで沈黙を統制できるか（AFが許可したときだけ話す縛りが効くか）」のテスト**
