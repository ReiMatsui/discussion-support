# 最終報告: 「理由の前提を根拠発言とともに明示する支援」の検証（2026-10-19）

判定と評価はすべて Claude（時点判定者19、事後評価者2）によるもので、人による独立した確認はしていない。ログで確かめたのは、対象場面の存在、抽出・提示の妥当性、不要介入、自動処理の精度で、参加者への効果ではない。

## 1. 結論: 何が通り、何が通らなかったか

**結論:** この案を主研究として採用しない。

- 事前に固定した基準を機械的に当てると、評価の分かれの扱いで「一度修正してから進む」と「採用しない」に分かれた。支援出力が2件しかないためである。
- 基準1 が支援の対象ではなく前提差の存在を数えていた欠陥も、検証中に分かった（基準は変更していない）。
- この2点を明示したうえで、次の事実から「採用しない」と判断した。

**通ったもの:**

- 前提差は、3種類の課題（GAP、AMI、DeliData）のほぼすべての議論にあった。
- LLM による抽出:
  - 引用の実在: 868件中867件
  - 時点より後の発言の参照: 0
  - 「既に明示」の判断は、事後評価者2人とも27組中24組で正しいとした
- 提案手法の提示文は、静的案内・引用のみより具体的だった。

**通らなかったもの:**

- **支援の対象（参加者がまだ言葉にしていない前提差）がほとんどなかった。** 84時点中2時点、13議論中2議論で、どちらも AMI。GAP と DeliData では0。
- 全体分析で、判断に支障があったと読めた場面は0。
- 支援出力2件のうち1件は直後に人が自力で扱い、もう1件は境界例だった。
- 提示文はどちらも、評価を想定として扱った疑いがあり、長すぎた（313〜394字）。

## 2. 当初の仮説を支持した結果と、反証した結果

**支持した結果:**

- 理由が前提に依存する対は、課題の種類を問わず存在した。
- 探索用データには、前提差が言葉にされないまま、多数や一言の否定で決まった例があった（GAP01-X02）。
- 提案手法は、何に答えればよいかを示せる唯一の形だった。

**反証した結果:**

- 前提差の大部分は、参加者自身が最初の判定時点までに言葉にしていた（時点判定 25組中23組）。
- 前提差を判断に取り込む段階2〜4 も、事後の全体分析では多くの場面で自然に起きていた。
  - 段階3（採用・反駁・限定・留保）: AU1 35場面中33、AU2 42場面中34
- 支援の条件を満たしたのに判定から漏れた場面は0件（AU1・AU2）。
- 支援出力の1件は、約80〜110秒後に人が自力で同じ前提を扱った。

## 6. 現時点で言える有用性と、まだ言えない効果

**言えること:**

- LLM は、話者付きの書き起こしから、引用付きで前提差を拾い、それが既に言葉にされたかをかなり安定して判断できた（公開転記での結果）。
- その判断を使えば、「支援しない」ことはほぼ正しく決められる。

**言えないこと:**

- 提示が参加者の判断を良くするか。
- 日本語3人の議論で同じ分布になるか。
- 実時間の音声認識を通した精度（未検証）。

前提差を支援する場面の頻度について、小さな標本から一般的な発生率は断定しない。
