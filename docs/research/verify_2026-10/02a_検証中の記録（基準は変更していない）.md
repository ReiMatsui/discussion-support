## 2. 未読の発話を見せない仕組みについて

| 事項 | 内容 | 影響 |
|---|---|---|
| 暗号化 | 判定時点ごとに別の合言葉で暗号化した。元データ（GAP・AMI の zip と展開物、前処理済みの全文、DeliData）は、判定が終わるまで主作業者の合言葉で暗号化し、平文を消した | 他の時点のファイルは、合言葉がないと読めない |
| 担当の割り当て | 判定者 J-kNN は、各議論の N 番目の時点だけを担当した（19人） | 同じ議論の、より後の時点を同じ判定者が見ることはない |
| 平文の自動保存 | 出力の長い復号結果を、作業環境が自動で `tool-results/` に保存した（ES2005c・IS1000c の cp14〜cp18 の7ファイル）。このフォルダは他の判定者からも読める場所にあった | 判定者の操作記録を検査した結果、各判定者が開いたのは自分の時点のファイルだけだった（`results/subagent_access_check.txt`）。ただし、同時に動いた判定者が他のファイルを読めた状態だったことは事実として残る |
| インターネット | 判定者はネットワークを使えた。元データを取得しないよう指示したが、技術的には防いでいない | 操作記録に、データの配布元への接続はなかった |
| 復号の検査 | 判定の後、引用868件のうち867件が、示した発言 ID の発言に実在した。判定時点より後の発言を参照したものは0件 | 1件（TS3003c_cp15 の t81）は、引用が発言に見つからなかった |
